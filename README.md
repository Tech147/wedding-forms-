# wedding-forms-
මගේ ජීවන ගමනට අම්මා කෙනෙක් වගේ ආදරේ කරන, හිත හොඳ, සරල සහ සංවර සහකාරියක් සොයා ගැනීමට මෙම Form එක නිර්මාණය කර ඇත.  ඔබ මෙහි ලබා දෙන සියලුම තොරතුරු, දුරකථන අංක සහ ඡායාරූප සම්පූර්ණයෙන්ම රහස්‍ය ලෙස (Confidential) සුරක්ෂිතව තබා ගන්නා අතර, සුදුසු සහකාරිය සොයා ගැනීමේ අරමුණ සඳහා පමණක් භාවිතා කරනු ලැබේ.
